# 📋 Checklist des tests Dormant Stock avec requêtes SQL associées

> **Date d'analyse :** `2026-06-15` (à adapter)  
> **ID produit de test :** `123` (à remplacer par un ID réel)  
> **Période de vente :** 6 mois (ou 12 mois selon test)

---

## 0. Données de base

| Item | Requête SQL |
|------|-------------|
| Product exists in product_info | `SELECT * FROM product_infos WHERE product_id = 123` |
| Product is active | `SELECT is_active FROM products WHERE id = 123` |
| Has stock movement | `SELECT COUNT(*) FROM move_lines WHERE product_id = 123` |
| Present in STOCK warehouse | `SELECT w.id FROM warehouses w INNER JOIN warehouse_product wp ON wp.warehouse_id = w.id WHERE w.type = 'STOCK' AND wp.product_id = 123` |
| Present in SELF_SERVICE warehouse | `SELECT w.id FROM warehouses w INNER JOIN warehouse_product wp ON wp.warehouse_id = w.id WHERE w.type = 'SELF_SERVICE' AND wp.product_id = 123` |
| Present in TRANSFER warehouse | `SELECT w.id FROM warehouses w INNER JOIN warehouse_product wp ON wp.warehouse_id = w.id WHERE w.type = 'TRANSFER' AND wp.product_id = 123` |

## 1. Quantité physique mensuelle

| Item | Requête SQL |
|------|-------------|
| Function returns data | `SELECT * FROM dbo.fn_warehouse_product_qty_physical('2026-01-01', '2026-01-31') WHERE product_id = 123` |
| Covers 6-12 months | `;WITH MonthEnds AS (...) SELECT me.months_back, me.month_end, wpq.* FROM MonthEnds me CROSS APPLY dbo.fn_warehouse_product_qty_physical(...) wpq WHERE wpq.product_id = 123 ORDER BY me.months_back` *(voir requête complète en Étape 1.2)* |
| Quantities coherent | Vérifier que `last_move_quantity` correspond aux mouvements cumulés : `SELECT SUM(warehouse_quantity) FROM moves m INNER JOIN move_lines ml ON ml.move_id = m.id WHERE m.status = 'CONFIRMED' AND m.validated_at <= '2026-01-31' AND ml.product_id = 123` |
| Contains warehouse_id | La fonction retourne `warehouse_id` |
| Contains product_id | La fonction retourne `product_id` |
| Contains qty_physical | La fonction retourne `last_move_quantity` |
| Contains date | La fonction reçoit une date en paramètre |

## 2. Quantité totale mensuelle par produit

| Item | Requête SQL |
|------|-------------|
| Aggregation correct | `;WITH MonthEnds AS (...) SELECT months_back, product_id, SUM(ISNULL(qty,0)) AS total_qty FROM ... GROUP BY months_back, product_id` *(voir Étape 2)* |
| One row per product/month | `;WITH ... SELECT months_back, product_id, SUM(qty) AS total_qty FROM ... GROUP BY months_back, product_id` |
| Matches warehouse sum | Comparer `SUM(qty)` par entrepôt avec le total : `SELECT months_back, warehouse_id, SUM(qty) FROM WarehouseQtyByMonth GROUP BY months_back, warehouse_id` |

## 3. Présence en stock

| Item | Requête SQL |
|------|-------------|
| Months with qty > 0 identified | `SELECT months_back, total_qty FROM ProductQtyByMonth WHERE product_id = 123 AND total_qty > 0` |
| Stock months count correct | `SELECT COUNT(*) FROM ProductQtyByMonth WHERE product_id = 123 AND total_qty > 0 AND months_back BETWEEN 0 AND 11` |
| No missing active months | Vérifier qu'il n'y a pas de trous dans les mois : `SELECT DISTINCT months_back FROM ProductQtyByMonth WHERE product_id = 123` |

## 4. Ventes (6 et 12 mois)

| Item | Requête SQL |
|------|-------------|
| Sales 6 months correct | `SELECT SUM(quantity) FROM view_sales_document_lines WHERE product_id = 123 AND day >= DATEADD(MONTH, -6, '2026-06-15')` |
| Sales 12 months correct | `SELECT SUM(quantity) FROM view_sales_document_lines WHERE product_id = 123 AND day >= DATEADD(MONTH, -12, '2026-06-15')` |
| Sales = outputs | Comparer avec `total_sold_6m` et `total_sold_12m` du snapshot |
| Test no sales case | Exécuter pour un produit sans vente : `SELECT total_sold_12m FROM dormant_stock_snapshots WHERE product_id = X` |
| Test low sales case | Exécuter pour un produit à faible vente |
| Test regular sales case | Exécuter pour un produit à vente régulière |

## 5. Dates d'entrée en stock

| Item | Requête SQL |
|------|-------------|
| First entry date correct | `SELECT MIN(validated_at) FROM moves WHERE type = 'MOVE_IN' AND status = 'CONFIRMED' AND product_id = 123` |
| Last entry date correct | `SELECT MAX(CASE WHEN document_type_id = 2 THEN validated_at END) FROM moves WHERE type = 'MOVE_IN' AND status = 'CONFIRMED' AND product_id = 123` |
| No invalid dates | Vérifier que les dates sont cohérentes (`first_stock_date <= analysis_date`) |

## 6. CMUP et valeur du stock

| Item | Requête SQL |
|------|-------------|
| CMUP calculated | `SELECT cmup FROM dbo.fn_product_value_by_dates('2026-06-15', '2026-06-15') WHERE product_id = 123` |
| CMUP not null if stock exists | Vérifier `cmup IS NOT NULL` quand `quantity > 0` |
| Stock value correct | `SELECT quantity_physical * cmup AS stock_value FROM dormant_stock_snapshots WHERE analysis_date = '2026-06-15' AND product_id = 123` |
| No negative values | `SELECT MIN(quantity_physical), MIN(cmup), MIN(stock_value) FROM dormant_stock_snapshots WHERE analysis_date = '2026-06-15'` |

## 7. Classification

| Item | Requête SQL |
|------|-------------|
| Dormant logic correct | Vérifier que `classification = 'ASLEEP'` pour les produits avec rotation ≥ 12 mois |
| Slow moving logic correct | Vérifier que `classification = 'DEAD'` pour les produits sans vente 12 mois |
| Active logic correct | Vérifier que `classification = 'NORMAL'` pour les produits actifs |
| Out of stock logic correct | Vérifier que les produits sans stock ne sont pas classés (ils n'apparaissent pas) |

## 8. Produits fantômes

| Item | Requête SQL |
|------|-------------|
